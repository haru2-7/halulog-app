# ハルログ

起床を起点に、1日を3つか4つの小さな「日」に分けて過ごすための個人用時間ログアプリです。

元になった時間管理法：

1. 7時間寝る
2. 起床直後の1時間はがんばらない（ここで張り切りすぎると燃え尽きる）。残りの16時間を分ける
3. 分け方は 4/4/4/4時間（4つの日）か 6/5/5時間（3つの日）。固定の予定に合わせて選ぶ
4. （一番大事）どうせ1日は3〜4日あるのだから、ひとつの「日」がうまくいかなくても落ち込まない

## 使い方

- 「起きた時間」を入れると、ゆっくりゾーン（起床後1時間）と各ブロックの時刻が自動で決まります。
- 4日モード（4/4/4/4）と3日モード（6/5/5）を切り替えられます。
- 各ブロックには「やることをひとつ」と任意のメモだけを書きます。
- 「この日をおわる」を押すと、ハンコと紙吹雪でささやかにお祝いします。上部の星も点灯します。
- 「今日のログをコピー」で、その日の記録をプレーンテキストとしてコピーできます。

## データ保存について

- 入力内容はブラウザの `localStorage` に日付ごとに自動保存されます（キー： `halulog-v2:YYYY-MM-DD`）。
- 入力データは外部サーバーへ送信しません。端末やブラウザが変わると同期されません。

## ファイル構成

- `index.html`: アプリ本体です（HTML/CSS/JavaScriptを1ファイルに収めた構成）。
- `manifest.json`: ホーム画面追加時の表示設定です。
- `icons/`: アイコンです。
- `app.js` / `styles.css`: 旧バージョンのファイルです。現在は使いません（過去の記録として残しています）。

## iPhoneで使う場合

1. iPhoneのSafariで公開URL（GitHub Pages）を開きます。
2. 共有ボタンを押します。
3. `ホーム画面に追加` を選びます。
